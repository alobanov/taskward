Connect in three steps

  1. 1

    Let assistants in

    On your Mac, open Taskward’s Settings → Assistants and turn on Let assistants in. It is part of Pro.

  2. 2

    Copy the command

    The page shows a command with your own token in it. Tap Copy the command and run it once in Terminal:

    claude mcp add --transport http taskward http://127.0.0.1:47823/mcp \
  --header "Authorization: Bearer <token>"
  3. 3

    Ask Claude

    Start Claude Code anywhere and ask for a plan. It calls Taskward by itself; type /mcp to see it connected.

Tools

Taskward gives an assistant four tools: two read, one adds a plan, one sorts what is there. None of them ever deletes anything for good.

get_overview

Reads what is there: today’s date, your areas, the open projects with their headings, deadlines and counts of open tasks, your tags, and how many tasks wait in the Inbox and Today. An assistant calls it first, so a plan goes where things already are.

No parameters.

find_tasks

Open tasks of a list, a project or an area, or by words in their titles. Give one of these:

ParameterTypeWhat it is
listtextinbox, today (with This Evening), upcoming, anytime or someday
project_idida project from get_overview
area_ididan area from get_overview
querytextevery word matched in the title, big letters or small
limitnumberat most this many; 100 if not given

add_plan

Writes a plan in one go — all of it, or nothing if any part is wrong. Any of:

ParameterTypeWhat it is
areaslistnew areas, each with title and its projects; one named as an area you have is that one
projectslistnew projects: title, notes, when, deadline, area_id, tasks, and headings — each a title and its tasks
taskslistloose tasks: into the Inbox, onto a day, or into a project, heading or area you have, by project_id, heading_id, area_id

update_tasks

Changes tasks already there, many at once — all of it, or nothing if any part is wrong. For sorting the Inbox and tidying lists. Each update names a task by its id (from find_tasks) and gives only what changes:

ParameterTypeWhat it is
ididrequired
titletexta new title
notestextnew notes
whentextas in add_plan; inbox sends it back to the Inbox, out of any project
deadlineday or nullYYYY-MM-DD; null takes it off
remindertime or nullHH:MM; null takes it off
tags_addlisttags to put on, by name
tags_removelisttags to take off, by name
project_idid or nullthe project to file it in; null takes it out of its project
heading_idida heading of that project
area_idid or nullthe area to file it in
completetrue / falsedone, or open again
trashtrueputs it in the Trash; nothing is deleted for good

Undo

Whatever an assistant does shows a note at the foot of the window — “An assistant added 6 tasks”, or that it changed some — with Undo. A plan’s Undo takes out what it made: tasks, headings, projects, the areas and tags it made. A batch of changes is undone whole, each task back where and as it was. Nothing is ever deleted for good: a task an assistant throws out goes to the Trash. Missed the note? The last change waits in Settings → Assistants as Undo the assistant’s last change.

Security

  • Taskward listens only on the Mac’s own loopback, 127.0.0.1:47823: nothing on your network or the internet can reach it.
  • Nothing is answered without your token. New token on the same page shuts out every assistant connected before, until you connect it again.
  • A request sent by a web page is refused, so no site you visit can reach your tasks.
  • The door is open only while Taskward is open, the switch is on and Pro is.

Privacy

Taskward itself sends nothing anywhere: your tasks stay on your devices and in your iCloud. But what an assistant reads from Taskward goes to whoever runs it — Anthropic for Claude — as everything you tell it does.

Pro

Letting assistants in is part of Taskward Pro. Without it, the switch opens the offer; if Pro ends, the door shuts and everything written stays.

Questions

Does it work on iPhone?

The door is on the Mac. What is written there reaches your iPhone through iCloud within seconds.

Does Taskward have to be open?

Yes: the Mac app is the server. Closed, the assistant is told it cannot connect.

Which assistants?

Any agent that speaks MCP over HTTP: Claude Code, Codex, Gemini CLI, Grok, Cursor and the rest. Claude Code connects with the command above; any other, give it the address http://127.0.0.1:47823/mcp and the token as a Bearer header. Claude Desktop runs only local stdio servers; a bridge such as mcp-remote can stand between.

It says it could not open the port.

Another app holds port 47823. Quit it, or write to me.
