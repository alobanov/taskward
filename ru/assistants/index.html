Подключение в три шага

  1. 1

    Пусти ассистентов

    На Маке открой Настройки Taskward → Ассистенты и включи Пускать ассистентов. Это часть Pro.

  2. 2

    Скопируй команду

    На странице будет команда с твоим собственным токеном. Нажми Скопировать команду и один раз выполни её в Терминале:

    claude mcp add --transport http taskward http://127.0.0.1:47823/mcp \
  --header "Authorization: Bearer <token>"
  3. 3

    Попроси Claude

    Запусти Claude Code где угодно и попроси план. Он сам обратится к Taskward; набери /mcp, чтобы увидеть подключение.

Инструменты

Taskward даёт ассистенту четыре инструмента: два читают, один добавляет план, один разбирает то, что есть. Насовсем ни один из них ничего не удаляет.

get_overview

Читает, что есть: сегодняшнюю дату, области, открытые проекты с заголовками, дедлайнами и числом открытых задач, теги и сколько задач ждёт во Входящих и в Сегодня. Ассистент вызывает его первым, чтобы план лёг туда, где всё уже лежит.

Без параметров.

find_tasks

Открытые задачи списка, проекта или области — или по словам в названии. Укажи что-то одно:

ПараметрТипЧто это
listтекстinbox, today (вместе с Этим вечером), upcoming, anytime или someday
project_ididпроект из get_overview
area_ididобласть из get_overview
queryтексткаждое слово ищется в названии, без учёта регистра
limitчислоне больше стольких; по умолчанию 100

add_plan

Записывает план одним махом — целиком или, если где-то ошибка, никак. Любое из:

ПараметрТипЧто это
areasсписокновые области: title и их projects; область с тем же именем, что у тебя есть, — это она
projectsсписокновые проекты: title, notes, when, deadline, area_id, tasks и headings — у каждого title и свои tasks
tasksсписокотдельные задачи: во Входящие, на день или в твой проект, заголовок или область — по project_id, heading_id, area_id

update_tasks

Меняет задачи, которые уже есть, много сразу — целиком или, если где-то ошибка, никак. Чтобы разобрать Входящие и навести порядок в списках. Каждое изменение называет задачу по id (из find_tasks) и даёт только то, что меняется:

ПараметрТипЧто это
ididобязательно
titleтекстновое название
notesтекстновые заметки
whenтексткак в add_plan; inbox возвращает во Входящие, из любого проекта
deadlineдень или nullYYYY-MM-DD; null снимает
reminderвремя или nullHH:MM; null снимает
tags_addсписоктеги, которые надеть, по именам
tags_removeсписоктеги, которые снять, по именам
project_idid или nullпроект, куда положить; null вынимает из проекта
heading_ididзаголовок этого проекта
area_idid или nullобласть, куда положить
completetrue / falseвыполнена или снова открыта
trashtrueв Корзину; насовсем ничего не удаляется

Отменить

Что бы ассистент ни сделал, внизу окна появится записка — «Ассистент добавил 6 задач» или что он что-то поменял — с кнопкой Отменить. У плана она уберёт всё, что он сделал: задачи, заголовки, проекты, созданные им области и теги. Пачка изменений отменяется целиком: каждая задача вернётся туда и такой, какой была. Насовсем ничего не удаляется: выброшенная ассистентом задача уходит в Корзину. Пропустил записку? Последнее изменение ждёт в Настройках → Ассистенты: Отменить последнее от ассистента.

Безопасность

  • Taskward слушает только внутренний адрес самого Мака, 127.0.0.1:47823: из сети и из интернета до него не достучаться.
  • Без твоего токена он ничего не ответит. Новый токен на той же странице отключает всех подключённых раньше ассистентов, пока ты не подключишь их снова.
  • Запрос со страницы в браузере отклоняется, так что ни один сайт не доберётся до твоих задач.
  • Дверь открыта, только пока Taskward открыт, переключатель включён и есть Pro.

Приватность

Сам Taskward ничего никуда не отправляет: задачи остаются на твоих устройствах и в твоём iCloud. Но то, что ассистент прочтёт в Taskward, уходит тому, кто его запускает, — у Claude это Anthropic, — как и всё, что ты ему говоришь.

Pro

Пускать ассистентов — часть Taskward Pro. Без него переключатель откроет предложение Pro; если Pro закончится, дверь закроется, а всё записанное останется.

Вопросы

А на iPhone работает?

Дверь — на Маке. Что записано там, приедет на iPhone через iCloud за секунды.

Taskward должен быть открыт?

Да: сервер — это само Мак-приложение. Если оно закрыто, ассистент скажет, что не может подключиться.

Какие ассистенты подходят?

Любой агент, который умеет MCP по HTTP: Claude Code, Codex, Gemini CLI, Grok, Cursor и другие. Claude Code подключается командой выше; любому другому дай адрес http://127.0.0.1:47823/mcp и токен в заголовке Bearer. Claude Desktop запускает только локальные stdio-серверы; между ними можно поставить мост вроде mcp-remote.
