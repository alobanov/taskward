# taskward

The site of Taskward, a calm to-do list for iPhone and Mac: https://alobanov.github.io/taskward/

English at `/`, Russian at `/ru/`; the landing page, the privacy policy and support.

- `python3 tool/assets.py` lays the pictures in from the app's repository (`~/Development/polk`):
  the paper's tooth, the oak, the app's icon, the icons as one sprite, the store's screenshots.
- `python3 tool/build.py` writes the pages from one set of templates and both languages' words.
